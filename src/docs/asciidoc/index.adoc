== API

=== 인증

==== 토큰 갱신

리프레시 토큰(HttpOnly 쿠키)으로 새 액세스 토큰을 발급한다.

operation::auth-refresh[]

==== 로그아웃

리프레시 토큰 쿠키를 삭제하여 로그아웃 처리한다.

operation::auth-logout[]
