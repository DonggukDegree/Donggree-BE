== Overview

Donggree 서비스 API 문서입니다.

== API

=== 인증

==== 토큰 갱신

리프레시 토큰(HttpOnly 쿠키)으로 새 액세스 토큰을 발급한다.

operation::auth-refresh[]

==== 로그아웃

리프레시 토큰 쿠키를 삭제하여 로그아웃 처리한다.

operation::auth-logout[]

=== 사용자 관리

==== 온보딩 정보 저장

카카오 로그인 후 최초 1회 학번과 이름을 입력받아 회원 정보를 완성한다.

operation::user-onboarding[]

==== 사용자 정보 조회

로그인한 사용자의 학번, 이름, 닉네임을 조회한다.

operation::user-info[]

==== 사용자 정보 수정

로그인한 사용자의 학번, 이름, 닉네임을 수정한다. 본인 인증 완료 후에는 닉네임만 변경 가능하다.

operation::user-info-update[]

==== 회원 탈퇴

로그인한 사용자의 계정을 탈퇴 처리한다. soft-delete 방식으로 처리되며, 동일 카카오 계정으로 재로그인 시 재활성화된다.

operation::user-delete[]

=== 관리자 커리큘럼 관리

==== 과목 분류 조회

과목 분류를 동적 다중 필터로 조회한다. 각 필터(areaTypeIds·courseTypes·years)는 여러 값을 지정할 수 있고, 지정하지 않으면 전체 조회다. areaTypeIds·courseTypes는 하나라도 일치(IN), years는 지정 연도 중 하나라도 적용 입학년도 범위(start≤year≤end)에 포함되면 매칭(OR)한다. 응답에는 area_type_id 대신 영역 이름(areaName)과 과목 tag가 포함된다.

operation::admin-course-classification-search[]

==== 과목 분류 배치 업서트

등록·수정을 구분하지 않고 여러 과목 분류를 한 번에 변경한다. 각 항목의 id가 null이면 신규 등록, non-null이면 전체 교체(수정)다. 전체가 하나의 트랜잭션으로 처리되어 일부라도 실패하면 모두 롤백된다. 결과 ID 목록을 입력 순서대로 반환한다.

operation::admin-course-classification-upsert[]

==== 이수 영역 조회

이수 영역 전체를 조회한다. 과목 분류 필터의 선택지로 사용된다.

operation::admin-area-type-list[]

==== 규칙 종류 조회

규칙 종류(rule_type) 전체를 조회한다. 졸업 규칙 필터의 선택지로 사용된다. 읽기 전용.

operation::admin-rule-type-list[]

==== 졸업 규칙 조회

졸업 규칙을 동적 다중 필터로 조회한다. ruleTypeIds·courseTypes는 하나라도 일치(IN), 미지정=전체. courseType은 rule_type 소유 컬럼이며, 정렬은 course_type(NULLS LAST) 그다음 rule_type_id 순이다. 응답에 rule_type 정보와 ruleConfig(JSON 객체)가 포함된다.

operation::admin-graduation-rule-search[]

==== 졸업 규칙 배치 업서트

등록·수정을 구분하지 않고 여러 졸업 규칙을 한 번에 변경한다. 각 항목의 id가 null이면 신규 등록, non-null이면 전체 교체(수정)다. 전체가 하나의 트랜잭션으로 처리되어 일부라도 실패하면 모두 롤백된다.

operation::admin-graduation-rule-upsert[]

==== 졸업 요건 세트 목록 조회

졸업 요건 세트를 동적 필터로 조회한다(요약, 연결 규칙 미포함). departmentId는 특정 학과, collegeId는 해당 단과대 소속 학과 전체(둘 다 주면 교집합), year는 단일 연도로 적용범위(start≤year≤end)에 포함되는 세트만. 미지정=전체. 연결 규칙 ID는 단건 상세 조회에서 제공한다.

operation::admin-requirement-set-list[]

==== 단과대 목록 조회

단과대 목록을 id·이름과 함께 조회한다. 졸업 요건 세트 필터·등록 드롭다운의 선택지로 사용된다.

operation::admin-college-list[]

==== 학과 목록 조회

학과 목록을 id·단과대(id·이름)·학과명과 함께 조회한다. collegeId를 주면 해당 단과대 소속만, 미지정이면 전체. 사용자는 이름을 보고 고르고 프론트는 id로 요청/응답한다.

operation::admin-department-list[]

==== 졸업 요건 세트 단건 조회

세트 1건과 연결된 졸업 규칙 ID 목록을 조회한다.

operation::admin-requirement-set-detail[]

==== 졸업 요건 세트 생성

새 졸업 요건 세트를 만들고 선택한 졸업 규칙들을 연결한다. 버전은 요청으로 받지 않고 서버가 (학과, 적용년도) 단위로 1부터 자동 채번한다. 활성으로 등록하면 같은 학과에 적용년도가 겹치는 다른 활성 세트가 없어야 하며, 겹치면 409를 반환한다. 생성된 ID를 반환한다.

operation::admin-requirement-set-create[]

==== 졸업 요건 세트 수정

세트의 정보(적용년도·설명·이미지·활성)와 연결 규칙을 전체 교체(PUT)한다. 학과·단과대·버전은 생성 시 확정되어 수정할 수 없으므로 요청에 포함되지 않는다. 적용년도가 바뀌면 버전을 새 (학과, 적용년도) 기준으로 다시 부여하고 그대로면 기존 버전을 유지한다. 활성으로 둘 경우 적용년도가 겹치는 다른 활성 세트가 없어야 한다(겹치면 409).

operation::admin-requirement-set-update[]

=== 학업 정보

==== 성적표 조회

로그인한 회원의 성적표 메타 정보와 수강 이력 전체를 조회한다. 메타에는 단과대학명·학과·총취득학점·평점 평균·성적표 생성/수정 시각이 포함되며, 수강 이력은 학기 오름차순으로 그룹핑하여 반환한다.

operation::transcript-get-report[]

==== 성적표 등록

취득교과목 영역별 분류표 PDF를 업로드하면 자동으로 파싱하여 학업 정보를 저장한다. 기존 성적표가 있으면 소프트 삭제 후 새로 생성한다.

operation::transcript-create[]

==== 수강 이력 수정

변경 후의 전체 수강 이력 목록을 받아 기존 이력을 통째 치환한다(수정·삭제·추가). 치환 후 총취득학점과 평점 평균(GPA)을 재계산하여 전체 수강 이력과 함께 반환한다. 메타 정보는 수정할 수 없다. 성적표가 없으면 404를 반환한다.

operation::transcript-update-course-records[]

=== 학업 리포트

==== 학업 리포트 조회

로그인한 회원의 졸업 요건 판정 결과를 조회한다. 전체 달성률 요약과 courseType별 이수 현황을 반환한다.

operation::graduation-get-report[]

성적표가 없으면 404(GRADUATION404_1), 학생의 학과·입학년도에 적용 가능한 활성 졸업 요건 세트가 없으면 404(GRADUATION404_2)를 반환한다. 적용 가능한 활성 세트가 없을 때의 응답은 다음과 같다.

operation::graduation-get-report-no-requirement-set[]

==== 영역별 이수 현황 조회

courseType 내 areaType별 상세 이수 현황을 조회한다. areaType별 이수 과목 목록(필수/선택), 미충족 사유, 해당 courseType 전체 학점 현황을 반환한다.

operation::graduation-get-area-detail[]

=== 자주 묻는 질문(FAQ)

==== FAQ 목록 조회

FAQ를 최신순으로 조회한다. 읽기 전용이며 비로그인 상태에서도 호출할 수 있다(화면의 '자주 묻는 질문'이 홈 푸터에 있다). 목록 한 건이 곧 아코디언 한 줄이라 제목과 본문을 함께 반환한다. 본문은 마크다운이 아닌 줄바꿈 포함 평문이다.

operation::faq-list[]

`tag`를 주면 해당 태그만 조회한다(SERVICE=서비스, COMMON=공통, MAJOR=전공). 미지정이면 전체이며, 화면 상단 칩의 '전체'가 여기에 해당한다.

operation::faq-list-by-tag[]

=== 관리자 FAQ 관리

==== FAQ 등록

FAQ를 등록하고 생성된 ID를 반환한다. `tag`는 SERVICE·COMMON·MAJOR 중 하나를 반드시 지정해야 하며, 누락하면 400(`VALID400_1`)을 반환한다.

operation::admin-faq-create[]

==== FAQ 수정

FAQ의 태그·제목·본문을 전체 교체한다. 존재하지 않으면 404(SUPPORT404_1)를 반환한다.

operation::admin-faq-update[]

==== FAQ 삭제

FAQ를 삭제한다. 존재하지 않으면 404(SUPPORT404_1)를 반환한다.

operation::admin-faq-delete[]
